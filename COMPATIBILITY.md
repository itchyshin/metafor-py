# Compatibility with R metafor 5.2-1

This project provides a staged native Python API with its own functions and result types. R metafor 5.2-1 is the comparison release; current claims apply only to the cases listed here. The full exported-name inventory and longer-term parity target are in [COVERAGE.md](COVERAGE.md).

| Capability | Status | Current native scope and limits |
|---|---|---|
| 2×2 effect sizes | partial | `escalc_rr`, `escalc_or`, and `escalc_rd` compute log risk ratios, log odds ratios, and risk differences with their large-sample sampling variances. The four zero-cell policies (`only0`, `all`, `if0all`, `none`) are represented by `to`; the default is `add=0.5`, `to="only0"`. Other measures, inputs, and `escalc()` options are unsupported. |
| Univariate FE and REML | partial | `fit_meta()` fits matrix-design models with FE or one-component REML. BCG estimates, the zero-heterogeneity boundary, local-maximum safeguard, and single-study boundary are checked against the pinned reference. Zero sampling variances are rejected. Small-sample tests and alternative interval methods are unavailable. |
| Missing and invalid rows | partial | Missing and non-finite rows are omitted with a Python runtime warning, and original row indices are retained. Warning text and categories differ from R. Zero sampling variances are rejected explicitly. |
| Formula and table input | partial | `fit_meta_formula()` uses the optional pandas/Patsy adapter. Numeric formula and row alignment cases are checked; full R formula semantics, categorical contrast parity, and every option are unsupported. The dependent-effects table adapter has the same limits. |
| Mean and new-study intervals | partial | `MetaResult.predict()` returns normal intervals for supplied design rows. A new-study interval is available for supported REML fits; it is unavailable for FE fits. These are not all `predict.rma()` options. |
| Forest output | partial | `forest_plot_data()` returns study intervals and an optional pooled summary on the log-risk-ratio scale. `write_forest_svg()` renders one native SVG form using the Python standard library; it does not reproduce `forest.rma()` layout or graphical options. |
| Supplied phylogenetic correlation | partial | `fit_phylo()` fits one species-level variance component using a supplied, labelled correlation matrix. Zero-boundary and interior synthetic cases are checked against R. If the random-effect design is contained in the fixed-effect design, REML warns and fixes the unidentifiable variance at zero. Tree estimation and unseen-species prediction are unsupported. |
| Dependent-effects GLS and REML | partial | `fit_meta_cov()` accepts a supplied sampling covariance `V` and supplied PSD covariance kernels. Correlated GLS, a two-component nested fit, and a two-outcome unstructured covariance fit are checked on fixtures. At most eight independent scalar components are accepted. These fixtures do not cover all `rma.mv()` families or options. |
| Nested random intercepts | partial | `fit_meta_nested()` builds indicator kernels from grouping vectors. Inner labels must include parent labels as tuples to avoid collisions. Other crossed or correlated structures are not claimed. |
| Two-outcome unstructured effect | partial | `fit_meta_un()` fits a PSD 2×2 within-study covariance with supplied sampling `V`; the synthetic 20-study case matches the pinned R reference. Three or more outcomes and other `struct` values are unsupported. |
| Dependent-effects formula/table adapter | partial | `fit_meta_cov_formula()` uses the optional pandas/Patsy adapter and retains original row IDs while masking both axes of `V`. Numeric formula and row-order cases are checked; categorical contrast parity and full R formula semantics are unsupported. |
| Other model families and inference | unsupported | GLMM, Mantel–Haenszel, Peto, location-scale, selection models, AR/CAR and spatial structures, estimated sampling correlations, profile intervals, Knapp–Hartung inference, and the broader diagnostic suite are not implemented. |

## Reference and dependencies

Reference values are tied to [CRAN metafor 5.2-1](https://cran.r-project.org/src/contrib/metafor_5.2-1.tar.gz), SHA-256 `25c421cf52279294b11ab3166adfeb327dd22034a03a46487f081a19a163339b`. The archive and normalized version are recorded in [reference provenance](reference/v1/PROVENANCE.md). The Python package does not call R and does not need the R package at runtime; R is used to regenerate the saved fixtures. The base package depends on NumPy and SciPy. Formula/table adapters need the optional pandas/Patsy extra; the SVG helper itself uses only the standard library.

The long-term goal is full parity across the public functions and documented options of the pinned R release, with native Python documentation for each implemented function and option. The staged roadmap is inventory, KNHA small-sample inference, the actual Berkey data example, then broader families and option coverage. See [COVERAGE.md](COVERAGE.md).
