How to read this page

Each row compares the same fixture and statistical target across the pinned R reference and both native implementations. Variance components allow 1e-6 absolute plus 1e-4 relative error; other estimates allow 1e-6 absolute plus 1e-5 relative error; small heterogeneity p-values use 1e-24 absolute plus 5e-4 relative error. Tests also cover a hand-calculated GLS case, missing-row masking on both covariance axes, reused nested labels, and a zero-variance boundary.

Example model definitions follow the upstream rma.mv reference. These fixtures use original synthetic data, not the Berkey dataset.
