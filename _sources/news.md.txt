# News

## Current status

`metafor-py` is experimental and unreleased. The source tree is currently
versioned as `0.1.0`; no Python package release has been published. This page
will list dated changes when a release or user-facing milestone is ready.

The current documentation includes 21 focused tutorials, a BCG getting-started
walkthrough, a function reference, and five fixture comparison reports. Their
scope is limited to the methods and cases described in the
[compatibility table](https://github.com/itchyshin/metafor-py/blob/main/COMPATIBILITY.md).
