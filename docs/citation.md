# Citation

## Citing this Python port

`metafor-py` is experimental and unreleased, so it does not yet have a
versioned publication or DOI. When reporting results from this code, cite the
source repository and identify the exact commit or archived source snapshot
used:

> Nakagawa, S., Yang, Y., & Viechtbauer, W. *metafor-py: Native Python methods
> for meta-analysis*. Experimental software, version 0.1.0 (unreleased).
> [https://github.com/itchyshin/metafor-py](https://github.com/itchyshin/metafor-py).

The names above are the project-intended team for this port. This citation does
not imply that each named person has accepted a project role. Wolfgang
Viechtbauer is separately the author of the upstream R package.

## Citing the upstream R package

If your work relies on the R package `metafor` or its methods, cite the
upstream software as its authors request and consider citing its methods paper:

> Viechtbauer, W. (2010). Conducting meta-analyses in R with the metafor
> package. *Journal of Statistical Software*, 36(3), 1–48.
> [https://doi.org/10.18637/jss.v036.i03](https://doi.org/10.18637/jss.v036.i03).

The Python port is a separate implementation, and its fixture checks do not
replace citation of sources, datasets, or methods used in a particular
analysis.
