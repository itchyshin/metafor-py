Differences from R metafor

This page links the current tutorial set to its function-level compatibility record. The status applies to a named function or option and fixture, not to the whole package.

Status

Meaning

Verified

Exercised against R metafor 5.2-1 using the recorded fixture and tolerance.

Partial

The listed subset is checked; other options or edge cases remain incomplete or unverified.

Unsupported

The function or option is not implemented.

Intentional difference

The port behaves differently by design; the consequence is documented.

Read COMPATIBILITY.md for the detailed table. Reference inputs and outputs are generated by the scripts under reference/; the ports run without R. The R release archive SHA-256 and the BCG, dependent, and phylogeny fixture provenance are recorded alongside those files.

The local BCG, dependent-effects, and phylogeny pages compare R, Python, and Julia results. They are local HTML files and are not hosted.
