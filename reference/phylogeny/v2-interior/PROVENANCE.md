# Synthetic phylogenetic interior fixture

This original five-observation fixture has three labelled species, repeated observations for two species, positive sampling variances, and a supplied positive-definite correlation matrix with unequal off-diagonal entries. It contains no copied dataset, tree, figure, or prose. Its R reference is generated by generate.R using metafor 5.2-1 and rma.mv with one species random intercept, the supplied correlation matrix, Rscale none, and REML. The fixture is synthetic software-validation material under GPL-2.0-or-later and makes no biological claim.

## Regeneration

Set `METAFOR_SOURCE_ARCHIVE` to the [CRAN 5.2-1 source archive](https://cran.r-project.org/src/contrib/metafor_5.2-1.tar.gz).
The generator checks SHA-256 `25c421cf52279294b11ab3166adfeb327dd22034a03a46487f081a19a163339b`
and the installed metafor version. Run `Rscript generate.R` from this fixture
directory with the pinned R library active. The repository's `reference/v1/PROVENANCE.md` lists the reference runtime
and dependency versions.
